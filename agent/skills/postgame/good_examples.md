# 写法参考

这是一篇已核对比分和方向的真实赛后样稿，只示范行文、取舍和复盘方式。它不是其他比赛的事实来源；不得照抄球队、球员、数字、赛果和盘口。每场事实与方向只采用本次冻结输入。

绿军半场占先机
活塞逆风夺胜局

半场领先13分，最后却输了8分。凯尔特人在底特律把好开局打丢了，活塞121比113赢下揭幕战。我赛前看好波士顿，支持凯尔特人让1.5分，这个判断错了。

我当时期待的是塔图姆和乔治两个持球点，让活塞的防守不断做选择。乔治交出了38分，塔图姆只有13分、三分7投0中，得分重心明显偏向一侧。不过塔图姆还有11次助攻，组织上的贡献也得算进去；不能因为输了球，就把他的整场表现一笔抹掉。我原先寄望双锋线持续拉开分差，最终结果没有兑现这个设想。

活塞赢球的得分账很直接：运动战得分93比97落后，罚球得分却是28比16领先。波士顿投篮多挣了4分，在罚球线上又丢回12分，终场正好输8分。再加上篮板49比39，主队在投篮之外拿到了足够的补充。赛前那点对客队的倾向，没能抵住这些差额。

比赛的反差也不只在最后几分钟。凯尔特人带着58比45进入中场，活塞下半场拿到76分，波士顿只有55分。前半场的领先是真实的，后半场被翻过去同样真实；开局比分顺着预测走，不能替整场判断兜底。

大小分方向看对了，数值却仍低估。赛前预计总分222.5，冻结市场线218.5，我选大分；实际234分，比预测高11.5分。所以这场该分开记：胜负和让分都错，大分方向命中，总分预测也没有准到可以轻描淡写。

下一次再支持这样的让分方向，我需要单独检查：持球得分带来的优势，有多少余地去抵住罚球和篮板上的损失。这一晚，凯尔特人的双锋线没有把比赛带进我预想的结局，底特律用另一张得分账收走了胜利。
