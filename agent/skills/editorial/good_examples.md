# 编辑修订后的正面范文

这篇样稿沿用用户认可的体育评论文风，已修正后来被否定的机械开场和无依据的历史战术断言。只学习叙述、人物互动与判断推进；它不是新比赛的事实来源，也不是当前预测或盘口。不要套用球队、人物、剧情和数字。

## 正文示例

纽约升旗迎旧敌
老詹领军再叩关

纽约的揭幕夜偏偏请来了76人，还是那支几个月前被他们横扫的球队。如今费城带着詹姆斯和布朗回来，谁都想看看：纽约熟悉的那个对手，这次还能不能用老办法对付？

我最想看的是马克西身边多了詹姆斯之后，球会怎么走。马克西被围住时，可以先把球交出来，自己继续往空当跑；詹姆斯若能在防线重新站稳前把球送到，布朗再沿另一侧冲进来，纽约就得跟着他们来回补位。这是费城这套新组合最让人期待的地方：进攻被挡住第一条路之后，还有人能找到下一条。

但让我选方向，我还是站尼克斯，让4.5分可以支持。

我更信任的是布伦森和唐斯的半场配合。布伦森叫掩护，唐斯往外拉，防守就得决定内线跟到哪里。如果恩比德上提接持球人，身后需要有人补篮下，弱侧便可能多一次传球机会；如果他守得深，布伦森就有机会在中距离停下来。对纽约而言，关键是把这个选择反复提出来，而费城要在每一回合里把补位接好。

我认为纽约更容易持续找到这样的机会。单次失位只是一两分，连续几次出球快过协防，优势才可能攒到覆盖让分的位置。这也是我支持尼克斯的原因，比赛里能不能做到，还得看费城的轮转回应。

费城当然有还手的办法。布朗可以在配合断掉时自己往里冲，詹姆斯可以寻找协防身后的出口；纽约一旦挡不住第一步，就会被迫不断补洞。如果这条路被费城打顺，纽约熟练的半场进攻也未必来得及发挥。

总分我更偏小，但看得没有让分那么重。它需要纽约拿到足够多的半场回合，让费城耐着性子寻找内线，几位持球人再去调整彼此的位置。可只要詹姆斯拿下篮板就推、马克西先冲出去，比赛就可能快起来。这条反例很具体，开球后就能看见。

所以我更支持纽约的让分方向，小分只是次选。先看布伦森能不能反复迫使内线做选择，再看詹姆斯能不能赶在纽约落好防线前，把球送到马克西手里。升旗仪式结束以后，这两件事才是比赛真正好看的地方。
