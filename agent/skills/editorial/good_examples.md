# 纽约的庆功宴，76人带着詹姆斯来赴约

明早，尼克斯要在麦迪逊花园升起冠军旗。76人得在旁边看着。

这场面多少有点扎心。几个月前，纽约踩着横扫费城的那轮系列赛一路夺冠；现在冠军准备领戒指，老对手却带着詹姆斯和杰伦·布朗回来了。揭幕战就碰上这两队，连客套的空间都没留。

费城当然有搅局的本钱。去年马克西一被围住，进攻就容易难受；现在旁边站着詹姆斯，尼克斯再往持球人身上扑，得先想想身后会漏掉谁。我最期待的画面，是詹姆斯拿下篮板直接推，马克西沿着边线冲出去，布朗跟着杀向篮下。让这几个人跑起来，纽约的升旗夜完全可能变成一场追逐战。

但让我选方向，我还是略站尼克斯，让5.5分可以支持。

原因就在布伦森手里。他不需要陪费城比谁跑得快，只要一次次叫挡拆，把问题交给恩比德：你出来，还是不出来？退一步，中距离可能就给了；往前迎，身后又得有人补。詹姆斯能让费城的进攻聪明起来，可另一端谁补篮下、谁回外线，这些选择仍得五个人一起完成。尼克斯值得看好的地方，是这套进攻不必临场重新搭建，更容易连续找到同一种机会。我认为这种半场进攻的稳定性，有机会把几次防守迟疑累积成六分以上的差距，因而支持让分方向。

当然，费城也有还手的办法。布朗能在配合断掉时继续往里冲，詹姆斯能找到协防留下的出口。尼克斯如果守不住第一步，逼得全队不停补洞，那“冠军班底更熟练”这句话，很快就会变得没什么用。

至于231.5的小分，我会看得轻一点。

它成立的剧本，是纽约把比赛拖回半场，费城得耐着性子寻找恩比德，几位持球核心还要摸索谁先攻、谁接着攻。可只要詹姆斯和马克西把转换打出来，这个剧本就可能被撕掉。况且恩比德近期已经正常训练、参加季前赛，不能先替他安排一个“带伤限时”，再拿这个理由支持小分。

所以，我更支持尼克斯让分，小分只是次选。明早先看布伦森能不能把恩比德反复叫进挡拆，再看詹姆斯能不能在纽约落好防线前，把球送到马克西手里。

冠军旗归纽约。旗升完以后，这支新76人到底有多难对付，才正式开始见分晓。
