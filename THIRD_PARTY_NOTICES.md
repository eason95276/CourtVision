# Third-party materials

MIT covers original code/docs, not third-party data, trademarks, logos, news,
models or dependencies. This independent project is not affiliated with NBA/ESPN.
Logos use existing external ESPN URLs; no downloaded logo pack is redistributed.
Raw articles, full NBA/ESPN datasets, database/model bundles and provider responses
are excluded. Provider terms still apply; source links do not grant reuse rights.

Small examples contain factual score/statistic fields and original analysis, not an
openly licensed replacement dataset. Lakers/Warriors display includes manually
curated portfolio content, not untouched model output. Full production/evaluation
reruns require separately obtained licensed assets and optional credentials. The
private frozen evaluation corpus remains local. Only the static product is turnkey.

## Frontend typefaces

The frontend bundles DSEG7 Classic Bold by keshikan and Bebas Neue by Ryoichi Tsunekawa.
Both are licensed under the SIL Open Font License 1.1. Their license files are
distributed alongside the font files in `v2/frontend/static/fonts/` and copied
into the built site's `fonts/` directory. These fonts render the shot-clock
brand, countdown digits and compact numeric displays.
