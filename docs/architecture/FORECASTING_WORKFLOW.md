# 两阶段预测

## 实际执行顺序

1. 根据已通过上游赛前校验的资料，构建不含市场信息的篮球输入。
2. 使用 Forecasting Skill 请求独立预测，检查数值和证据引用。
3. 保存 independent.json，并校验保存内容的摘要哈希。
4. 开放盘口及依赖市场的模型结果，请求市场复核。
5. 保存最终预测、保持或调整的理由、证据引用和程序计算的调整量。

第一步包含 Pure、球队数据、阵容、伤病、赛程、历史交手和赛前消息。
Residual、Official、市场差异、赔率、让分、总分线和热门球队标签留到复核阶段。
原始模型层继续保持独立，AI 判断不覆盖 Official Numeric Forecast。

Residual 层时保留兼容；其他来源不明确的旧缓存模型值在独立阶段为 unavailable。
